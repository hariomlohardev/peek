# Assets

This folder holds demo media for `README` and launch.

![demo](https://github.com/hariomlohardev/peek/blob/main/peek/assets/demo.gif)

## Quick Generate (no external tools)

```bash
# Code-generated GIF + SVG via Pillow (primary, works on Windows/Linux/macOS)
python -m peek.tools.gen_demo
# or
python peek/tools/gen_demo.py
# outputs: assets/demo.gif (800x450, <3MB, ~15s) + assets/demo.svg

# HTML export (themed)
peek --html -o assets/demo.html
peek --theme dracula --html -o /tmp/preview.html
```

## Files

- `demo.gif` — 15s terminal demo (800×450, <3MB, loop, 10 fps, anthropic-pro themed). Scenes: title → help → no-tui → find → pack → theme carousel. Generated by `peek/tools/gen_demo.py` using Pillow; no `vhs`/`ffmpeg` required. Verify: `file assets/demo.gif` → `GIF89a`.
  - Regenerate: `python -m peek.tools.gen_demo --theme anthropic-pro`
  - Check size: `ls -lh assets/demo.gif` (must be <3 MB)

- `demo.svg` — Animated SVG alternative (SMIL, same scenes, cycles every 2.2s). Useful for README when GIF is heavy. Generated alongside GIF.

- `demo.html` — Self-contained HTML export via `peek --html -o assets/demo.html` (themed, `anthropic-pro` default). Regenerate on each release.

- `demo.tape` — `vhs` script (fallback if you have `vhs` installed). Example is kept in sync with the Python generator.

```tape
Output assets/demo.gif
Set Width 1200
Set Height 800
Set Theme "Catppuccin Mocha"
Set FontSize 14
Type "peek --help" Enter
Sleep 1000ms
Type "peek . --no-tui" Enter
Sleep 2000ms
Type "peek find \"auth\" ." Enter
Sleep 1500ms
Type "peek --pack --ask \"auth\" | head -20" Enter
Sleep 1500ms
```

Run: `vhs assets/demo.tape` (optional — Python generator is primary)

## Generating Now

```bash
python -m peek.tools.gen_demo          # gif + svg
peek --html -o assets/demo.html        # html
pytest peek/tests/test_demo_assets.py -v  # guards
```

Keep GIF <3MB: generator uses 128-color quantized, `optimize=True`. If you edit scenes, re-run and check `ls -lh`.
